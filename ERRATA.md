# Errata

This file is the public record of every time a published card script changed behaviour because a ruling or a rulebook revision said it should. Each entry states the old behaviour, the new behaviour, the rule key, the authority tier behind the change and the discussion that supports it.

## Append-only rule

Entries are never edited or removed, and index rows are never deleted. A correction is a new entry that links the earlier one. The entry format is in [`errata/TEMPLATE.md`](errata/TEMPLATE.md).

This file and the `errata/` directory are checked by `scripts/check-errata.mjs` in CI.
